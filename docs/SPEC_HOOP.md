# HULA HOOP モード 仕様書

タイトルメニューから選べる 2 つ目のモード。
**入力は自機ではなくオプション（輪）に力を加える**。フラフープのように、輪の回転に合わせて入力を
回し続けてパワーを溜め、逆方向に入れてパワーを落とさないようにするのがコツ。

共通仕様（画面・レンダラー・敵の見た目・デバッグパネルの基本操作）は [SPEC.md](SPEC.md) を参照。

## 1. 登場物

| 物 | 内容 |
|---|---|
| 自機 | 画面中央やや下（高さ 70%）に固定。入力方向へ `hoop_hip` px だけ腰を振る（見た目と手応えのため） |
| オプション（輪） | 1 個。自機を中心に円運動する |
| 敵 | 画面上部・左右の端から出現し、自機へ向かって歩いてくる |

## 2. 操作

| 入力 | 内容 |
|---|---|
| STICK（既定） | 画面のどこでもタッチでフローティングスティック。スティックの向き・倒し量が入力ベクトル |
| SWIPE | 指を動かす速度ベクトルが入力ベクトル（`hoop_swipe_ref` px/s で 1.0）。画面上で指をぐるぐる回す |
| 矢印キー / WASD | PC 確認用 |
| MENU | タイトルへ戻る |

操作方式は DEBUG パネルの `Input: STICK/SWIPE` で切り替える。

## 3. 輪の運動

輪の状態は **角度 θ、角速度 ω（符号 = 回転方向）、半径 r**。

### 3.1 入力とパワー

- 輪の位置での接線（進行方向）を `t` とし、入力ベクトル `u` の進行方向成分を `along = u · t × sign(ω)` とする。
- 入力と進行方向の角度差で効果が変わる:

| 角度差 | 名前 | 効果 |
|---|---|---|
| 0°〜90°（along > 0） | 順入力 | `ω` を加速: `Δω = along × hoop_push × dt` |
| 90°〜`hoop_reverse_angle`（既定 120°） | 横入力 | 影響なし（半径が少し揺れるだけ） |
| `hoop_reverse_angle`〜180° | 逆入力 | 減速: `Δω = along × hoop_push × hoop_reverse_brake × dt` |

- `|ω|` の上限は `hoop_max_omega`。パワー = `|ω| / hoop_max_omega`（0〜100%）。
- 同じ向きに入れっぱなしにすると、輪が一周する間に順・横・逆が入れ替わり、ほとんど溜まらない（逆入力の分だけ減る）。
  **輪の少し先を指し続けるように入力を回す**のが正解。

### 3.2 パワーの維持と途切れ

- `|ω| >= hoop_min_omega` の間は「円運動が続いている」状態。**パワーは維持される**（`hoop_sustain_decay` は既定 0）。
  手を離しても回り続ける。
- `|ω| < hoop_min_omega` になると「途切れた（DROPPED）」状態:
  - 輪の半径が 55% に縮み（フラフープが落ちた表現）、色がグレーになる。
  - 入力していない間は `hoop_drop_decay` で止まっていく。
  - 入力の効きが `hoop_start_boost` 倍になり、向きを問わず回し始められる（逆入力扱いなし）。
    ゆっくり回し始めて、速度が乗ったら輪の先を指すのが立て直しのコツ。

### 3.3 半径

- 目標半径 = `hoop_radius + hoop_radius_gain × パワー`（速く回すほど輪が広がり、攻撃範囲が広がる）。
- 途切れている間は `hoop_radius × 0.55`。
- 入力の半径方向成分 × `hoop_radial_push` で半径が揺れる。バネ（k = 60, c = 9）で目標半径へ戻る。

## 4. 敵とスコア

- `enemy_interval` 秒ごとに、画面上部または左右の端から出現（同時最大 `enemy_max`）。
- 自機へ向かって `hoop_enemy_speed × (0.7〜1.3)` px/s で歩いてくる。
- **回っている間の輪**に触れると破壊（スコア +1、破片は輪の速度方向へ飛ぶ）。DROPPED 中の輪はすり抜ける。
- 自機に到達（距離 44px 未満）すると消えて **MISS +1**（モックなのでゲームオーバーは無し）。

## 5. HUD

| 表示 | 内容 |
|---|---|
| SCORE | 破壊数 |
| KEEP / BEST | 途切れずに回し続けている秒数 / 最高記録 |
| MISS | 自機に到達された数 |
| 下部ゲージ | POWER %、回転方向（CW/CCW）または DROPPED、角速度 |
| 自機から伸びる矢印 | 入力ベクトル。**緑 = 順入力（加速中）/ 赤 = 逆入力（減速中）** |
| 薄い円 | 輪の通り道（パワーが高いほど明るい） |
| Lines: ON 時 | 輪の位置の進行方向（青）と、入力の進行方向成分（黄） |

## 6. デバッグパネル（HULA HOOP 用）

プリセットは無し。`Reset` はこのモードの値だけを既定に戻す。

**Hoop タブ**

| キー | 表示名 | 既定 | 範囲 | 意味 |
|---|---|---|---|---|
| hoop_push | Push power | 8 | 1–40 | 順入力 1.0 あたりの角加速度 (rad/s²) |
| hoop_start_boost | Start boost x | 3.5 | 1–8 | DROPPED 中の入力の効き倍率 |
| hoop_reverse_angle | Reverse zone (deg) | 120 | 90–180 | これ以上ずれた入力を逆入力とみなす |
| hoop_reverse_brake | Reverse brake x | 1.6 | 0–5 | 逆入力の減速倍率 |
| hoop_min_omega | Min spin (break) | 2.5 | 0–8 | これ未満で途切れる (rad/s) |
| hoop_max_omega | Max spin | 10 | 4–40 | 角速度の上限 (rad/s)。10 ≒ 1.6 回転/秒 |
| hoop_sustain_decay | Decay while spinning | 0 | 0–1 | 回転中の自然減衰（0 = 完全に維持） |
| hoop_drop_decay | Decay after break | 1.2 | 0–5 | 途切れた後、入力なしのときの減衰 |

**Shape タブ**

| キー | 表示名 | 既定 | 範囲 | 意味 |
|---|---|---|---|---|
| hoop_radius | Radius | 150 | 60–320 | 基本半径 (px) |
| hoop_radius_gain | Radius gain at max | 70 | 0–200 | パワー最大時に広がる量 (px) |
| hoop_radial_push | Radial wobble | 900 | 0–3000 | 半径方向入力での揺れ |
| hoop_hip | Hip sway | 36 | 0–100 | 自機の腰振り幅 (px) |

**Game タブ**

| キー | 表示名 | 既定 | 範囲 | 意味 |
|---|---|---|---|---|
| hoop_swipe_ref | Swipe speed = 1.0 | 1400 | 300–4000 | SWIPE で入力 1.0 になる指の速さ (px/s) |
| hoop_enemy_speed | Enemy speed | 70 | 0–300 | 敵の歩く速さ |
| enemy_max | Enemy max | 10 | 0–30 | 敵の同時数（両モード共通） |
| enemy_interval | Enemy interval (s) | 0.8 | 0.1–3 | 出現間隔（両モード共通） |

### 調整の目安

- もっとシビアに: Reverse zone ↓（90° に近づける）/ Reverse brake ↑ / Min spin ↑ / Decay while spinning を少し上げる
- もっと気持ちよく: Push power ↑ / Reverse zone ↑ / Start boost ↑
- 手を離すと少しずつ落ちるフラフープらしさ: Decay while spinning = 0.05〜0.15

## 7. 検証済みの挙動（シミュレーション）

| 入力パターン | 結果 |
|---|---|
| 0.15 秒遅れで輪の 90° 先を狙う（人間を想定） | 約 2 秒でパワー 100% |
| 手を離す | 100% のまま維持 |
| 進行方向から 105° の入力（横入力ゾーン） | 変化なし |
| 真逆に入力 | 約 1 秒で DROPPED |
| 輪を見ずに一定速度でスティックを回す | 回転速度が合えば溜まるが、合わないと溜まらない（位相が合わない） |
